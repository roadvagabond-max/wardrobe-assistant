1. 🧭 Filozófia és Gondolkodásmód (Core Mindset & Principles)

A Sartorial Wardrobe Assistant nem egyszerű leltár-katalógus, hanem egy autonóm szabászati és stílustanácsadó rendszer. Célja a kapszula ruhatár tudatos építése, a meglévő ruhák variálhatóságának kimaxolása és a rossz döntések megelőzése.

✨ Olasz Sprezzatura & Kapszula Ruhatár

Kevesebb, de minőségi természetes kelme (100% gyapjú, kasmír, selyem, len, pamut, bőr). A mesterkéletlen elegancia, ahol a színek és textúrák találkozása természetes összhangot sugároz.

🛑 Zero-Mock & Anti-Hallucináció

Szigorú 100%-os valódi Gemini AI motor. Tilos a szimulált/kamu válaszok generálása. Ha egy webshop link nem azonosítható biztonsággal, a rendszer sosem talál ki fantomruhát (isUnknown: true).

🛍️ A Vásárlás Előtti 4 Döntési Pillér („Megvegyem?” Kontroll)
  1. 1. Pillér (Kombinálhatóság): Legalább 3 komplett szett generálása a meglévő ruhatár darabjaival párosítva.
  2. 2. Pillér (Stilisztikai Lefedettség & Duplikáció): Meglévő hasonló darab észlelése esetén figyelmeztetés a redundanciára és alternatív ajánlás.
  3. 3. Pillér (Személyes Illeszkedés & Szabás): Szabási eltérés (pl. Regular vs Slim dominancia) és egyéni szabályütközések azonnali jelzése.
  4. 4. Pillér (Anyagminőség & Műszál Auditor): 100% műszálas poliészter/akril/PU esetén lepontozás és 'Gondold Át / Kerülendő' minősítés.
👔 Sartorial Gallér- és Ujj-Harmónia Rendszer (Layering Matrix)
  • Ingdzseki (Shacket / Overshirt): Tilos alá hagyományos galléros inget venni (kettős gallér és kettős gombsor stílushiba). Kizárólag pólóval, finomkötött kereknyakúval vagy merinó garbóval hordandó.
  • Állógalléros ing (Mandarin / Mao / Grandad): Tilos zárt kötött pulóverrel vagy hajtókás öltönyzakóval párosítani. Önállóan vagy nyitott kardigánnal viselendő.
  • Garbó (Turtleneck):** Önálló bázisréteg; alá nem veszünk inget.
  • Kötelező Anatómiai Bázisréteg: Egy szett sem maradhat belső réteg nélkül (ing/póló); zakó vagy pulóver önmagában nem szerepelhet.
  • Szezonális Hőmérsékleti Védelem: Meleg időben (≥19°C) kizárt a csizma, bakancs és télikabát; hidegben (<14°C) támogatott a télikabát + zakó kettős réteg.

3. 🔄 A 10 Alapvető Munkafolyamat (Workflows Step-by-Step)

📸 Workflow 1: Ruhafelvitel & Multimodális AI Vision Elemzés Vision AI

Bemeneti csatornák: Közvetlen kamerafotó, galéria feltöltés, vágólap (Ctrl+V) vagy webshop URL / SKU termékkód.

Feldolgozás: A Canvas motor 640×640-re méretezi a képet. A Gemini 3.x felismeri a kategóriát, színt, anyagösszetételt, formalitást (1-5), stílus archetipust, szezonalitást, márkát és méretet, majd előtölti a szerkeszthető űrlapot és menti a Firestore-ba.

🛍️ Workflow 2: Vásárlás Előtti 4-Pilléres Döntéstámogatás Decision Control

Cél: Megelőzni a megbánt impulzusvásárlásokat még a próbafülkében vagy böngészéskor.

Lépések: 1) 3 komplett szett összeállítása meglévő gardróbbal; 2) Duplikáció és stilisztikai redundancia audit; 3) Szabási és testalkati illeszkedés ellenőrzése; 4) Műszál és anyagminőség pontozás. Egykattintásos átemelés a gardróbba.

👔 Workflow 3: Esemény- és Kulturális Dress Code AI Stylist Stylist Engine

Funkció: Esemény jellegének értelmezése (pl. techno klub, esküvő, tárgyalás), kulturális tiltólisták érvényesítése, gallérmátrix és kötelező bázisréteg kikényszerítése, helyi időjáráshoz és hőmérséklethez igazított rétegezési tanácsadás.

🧩 Workflow 4: Kapszula Ruhatár Gap Elemzés & Szezonális Audit Gap Analyzer

Audit logika: 1. prioritású téli lábbeli ellenőrzés (Chelsea/Chukka hiány azonnali jelzése), kategória telítettségi korlát (2+ felső esetén alapkategóriákra fókuszálás), Kapszula Ruhatár Index és szabásérzékeny keresőkifejezések generálása.

📏 Workflow 5: Gyártói Méretprofil & Kanonikus Márkanévtér Sizing Matrix

Intelligencia: A normalizeBrandName motor egyetlen kanonikus név alá fűzi a domaineket és variánsokat (pl. next.co.uk ➔ Next Direct). Kategóriánkénti bázisméreteket aggregál és márkánkénti illeszkedési mátrixot épít.

🧠 Workflow 6: Szabad Szöveges AI Stylist Tanítás & Egyéni Szabályrendszer Personal DNA

Működés: A felhasználó szabad szöveges tiltásai (pl. "Nem hordok pólóinget", "Csak 100% pamut") azonnal beépülnek a Stylist generátorba, a Gap elemzőbe és a Vásárlási Tanácsadóba (ütközéskor azonnali figyelmeztetés).

👔 Workflow 7: Saját Szett Összeállítása & 4-Dimenziós Sartorial Audit Manual Outfit Builder

Mérés: Interaktív ruha-összeválogatás után az AI 0-100% közötti pontszámmal értékeli a dress code összhangot, színharmóniát, anyagok találkozását és rétegezési komfortot, konkrét tuning javaslatokkal.

💬 Workflow 8: Szabad Szöveges Személyes AI Stylist Csevegés Master Chat

Kontextus: Teljes gardrób- és Stílus DNS ismeret. Bármely említett ruha interaktív kártyaként jelenik meg és kattintásra megnyílik a nagyfelbontású Lightboxban.

📱 Workflow 9: Mobil Web Share Target & Facebook Browser Integráció Mobile PWA

Élmény: Külső böngészőből vagy Facebook appból a termékoldal megosztásakor a Wardrobe Assistant közvetlen célalkalmazásként nyílik meg, és azonnal elindítja a 4-pilléres vásárlási tesztet.

🌐 Workflow 10: Autonóm Stílus-DNS Vezérelt Szabálykutató (Rule Mining) Search Grounding

Automatizmus: A felhasználó profiljához és gardróbjához igazított Google Search kereséssel friss nemzetközi szabászati szabályokat kutat fel, 7 naponta automatikusan frissítve a Firestore adatbázist.

4. 🗄️ Adatmodellek és Sémák (Data Models & TypeScript Interfaces)

4.1. ClothingItem (Ruhatári Elem Interfész)

interface ClothingItem {
  id: string;                      // Egyedi azonosító (pl. "item-1725450000000")
  name: string;                    // Megnevezés (pl. "Sötétkék Olasz Gyapjú Zakó")
  category: 'tops' | 'bottoms' | 'outerwear' | 'knitwear' | 'shoes' | 'accessories';
  subCategory?: string;            // pl. "blazer", "shirt", "loafer", "chelsea_boots"
  color: string;                   // Domináns szín (pl. "Sötétkék")
  colorHex?: string;               // Színkód hexában (pl. "#1e293b")
  material: string;                // Anyagösszetétel (pl. "100% Olasz Gyapjú (Nova Fides)")
  materialCategory?: 'natural' | 'blend' | 'synthetic';
  pattern?: string;                // pl. "Sima", "Halszálkás", "Kockás", "Csíkos"
  formalityLevel: 1 | 2 | 3 | 4 | 5; // 1: Casual, 5: Black Tie / Ultra Formális
  styleArchetype?: 'classic_sartorial' | 'smart_casual' | 'urban_minimalist' | 'casual_weekend' | 'streetwear';
  season: 'all' | 'summer' | 'winter' | 'transition';
  fit?: 'slim_tailored' | 'regular_fit' | 'relaxed_oversized';
  condition?: 'new_or_pristine' | 'good_daily' | 'worn_needs_care' | 'needs_replacement';
  brand?: string;                  // pl. "Boglioli", "Massimo Dutti", "Next Direct"
  size?: string;                   // pl. "50", "40 / M", "32/32", "42.5"
  productUrl?: string;             // Webshop termék link
  productCode?: string;            // SKU / Termékkód (pl. "SU415329")
  imageUrl: string;                // Base64 tömörített kép vagy CDN URL
  styleTips?: string[];            // AI viselési tanácsok
  createdAt: string;               // ISO Timestamp
}

4.2. UserProfile / StyleDNA (Felhasználói Stílus DNS)

interface UserProfile {
  uid?: string;
  name: string;
  height: string;                  // pl. "182 cm"
  weight: string;                  // pl. "79 kg"
  bodyType: 'trapezoid_athletic' | 'v_shape' | 'rectangle' | 'oval' | 'inverted_triangle';
  skinTone: 'warm_autumn' | 'warm_spring' | 'cool_summer' | 'cool_winter';
  gender: 'universal' | 'menswear' | 'womenswear';
  preferredStyles: string[];       // pl. ["classic_sartorial", "smart_casual"]
  favoriteColors: string[];        // pl. ["Sötétkék", "Tevebarna", "Krémfehér", "Bordó"]
  customStylingRules?: string;     // Szabad szöveges egyéni szabályok és tiltások
  brandSizes?: Record<string, string>; // pl. { "Boglioli": "50", "Eton": "40" }
  updatedAt: string;
}
