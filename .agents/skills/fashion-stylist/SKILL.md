# Fashion Stylist Skill

Ez a skill a felhasználó Személyes Stílus DNS-ét ötvözi az események kulturális, zenei és helyszíni dress code követelményeivel.

## Irányelvek és Szabályok:
1. **Önazonos Adaptáció:** A felhasználó saját stílusát (Quiet Luxury, Sprezzatura, Időtlen Klasszikus) fordítja le az adott alkalomra, nem kényszerít rá sablonos kliséket.
2. **Kulturális & Helyszíni Tiltólisták:**
   - *Techno / Rave / Club:* Szigorúan tilos az öltönyzakó, nyakkendő, és formális cipő. Helyette sötét/monokróm, légáteresztő, kényelmes rétegek kellenek.
   - *Esküvő / Gála:* Kötelező a strukturált elegancia (zakó, ing, elegáns cipő).
3. **3 Szettvariáció:** Mindig 3 különböző, de az eseményhez 100%-ban illeszkedő karakterű összeállítást generál.
4. **Indoklás:** Mindig adjon szöveges magyarázatot (`culturalFitReasoning`) az esemény és a szett összhangjáról.
